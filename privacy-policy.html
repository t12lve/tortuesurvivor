Politique de confidentialité — Tortue Survivor

Dernière mise à jour : 1 août 2026
Application Android : com.t12lve.TortueSurvivor

La présente politique décrit comment l’application mobile Tortue Survivor traite les informations. Le jeu fonctionne principalement hors ligne sur votre appareil.

1. Résumé

  • Pas de compte utilisateur obligatoire
  • Pas de publicité intégrée dans la version décrite ici
  • Pas de vente de données personnelles
  • Sauvegardes et réglages stockés localement sur l’appareil

2. Données stockées sur l’appareil

L’application peut enregistrer localement (stockage web / localStorage) : préférences, progression ou sauvegardes, et états de session.

Ces informations ne quittent pas votre téléphone via un serveur exploité par Tortue Survivor. Désinstaller l’application ou effacer les données de l’app les supprime.

3. Connexion Internet

L’application déclare la permission Internet (contenus web annexes éventuels). Aucune collecte d’identité n’est effectuée à des fins marketing dans la configuration actuelle.

4. Services tiers

La distribution via Google Play implique le traitement de données par Google selon leurs propres politiques. Tortue Survivor n’ajoute pas, dans la version actuelle, de SDK publicitaire ou d’analytique tierce dédiée.

5. Enfants

Le jeu contient de la satire politique et n’est pas destiné aux très jeunes enfants. Il ne cible pas spécifiquement un public de moins de 13 ans et ne collecte pas sciemment de données d’enfants.

6. Vos choix

  • Désinstaller l’application pour supprimer les données locales associées
  • Utiliser les réglages Android « Effacer les données » / « Stockage » de l’app

7. Contact

Questions relatives à cette politique : ouvrir une issue sur GitHub.

8. Modifications

Si le traitement des données change (analytics, compte, publicité, etc.), cette page et la section « Sécurité des données » de Play Console seront mises à jour.
